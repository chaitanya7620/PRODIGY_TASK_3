# PRODIGY_TASK_3
Web Development Task 3 – Prodigy Infotech Internship.  🎮 Tic Tac Toe Game (Web) Live Demo :- https://github.com/chaitanya7620 This is a Tic Tac Toe web application built using HTML, CSS, and JavaScript. The game supports Two Player mode as well as Player vs Computer mode with multiple difficulty levels.

# 📌 Features
✔️ Classic 3×3 Tic Tac Toe board
✔️ Two Player mode
✔️ Play against Computer
✔️ Difficulty levels:
Easy
Medium
Hard
✔️ Turn indicator
✔️ Win & draw detection
✔️ Restart game option
✔️ Responsive UI

# 🛠️ Technologies Used
HTML – Game structure
CSS – Styling and layout
JavaScript – Game logic and AI

# ▶️ How to Run
Download or clone this repository
Open index.html in any web browser
Start playing immediately
👉 No installation or server required

# 🎮 Game Modes
👥 Two Players
Both players play on the same device
Turns alternate between X and O
🤖 Vs Computer
Computer plays as O
Difficulty options:
Easy – Random moves
Medium – Winning & blocking logic
Hard – Minimax algorithm (smart AI)
# 🔁 Controls
Click on any cell to make a move
Use buttons to:
Switch game mode
Change difficulty
Restart the game
